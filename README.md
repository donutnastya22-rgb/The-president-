# The President — ЦАР (демоверсия 0.1)

Мобильная браузерная политическая RPG в газетной эстетике и с 2D-пиксельной сценой.

## Что внутри
- `index.html` — интерфейс приложения.
- `styles.css` — адаптивный дизайн для телефона и компьютера.
- `app.js` — игровая логика, выборы, цепочки событий, сохранение.
- `data/countries.json` — стартовые данные ЦАР и ссылки на источники.
- `data/car-events.json` — 36 событий из предоставленного JSON; структура исходных событий сохранена.
- `manifest.webmanifest`, `sw.js`, `assets/icon.svg` — установка как PWA и базовый офлайн-кеш.
- `firebase.json`, `firestore.rules` — заготовки для Firebase Hosting и Firestore.

## Запуск локально
Не открывайте `index.html` двойным нажатием: браузер может блокировать `fetch()` для JSON. Запустите локальный сервер из этой папки, например:

```bash
python -m http.server 8000
```

Затем откройте `http://localhost:8000`.

## Публикация на GitHub Pages
1. Создайте репозиторий и загрузите **содержимое** этой папки.
2. Откройте Settings → Pages.
3. В Build and deployment выберите Deploy from a branch, ветку `main`, папку `/ (root)`.
4. Сохраните и дождитесь публикации.

## Публикация через Firebase Hosting
1. Установите Firebase CLI и войдите в аккаунт.
2. В корне проекта выполните `firebase init hosting`.
3. Выберите существующий Firebase project; public directory — `.`; configure as single-page app — `No`; не перезаписывайте существующие файлы.
4. Выполните `firebase deploy --only hosting`.

`firebase.json` уже содержит базовую настройку Hosting. Если используете Firestore, отдельно включите его в консоли и примените `firestore.rules`. В текущей версии база не нужна: сохранение идёт в `localStorage` на устройстве.

## Как устроено сохранение
Автосохранение выполняется в браузере текущего устройства. Очистка данных сайта или другой браузер могут удалить/не увидеть сохранение. Облачной синхронизации пока нет.

## Стартовые параметры
Численность населения, территория, столица и валюта основаны на данных UN Data; показатели ВВП, электроэнергии и интернета — World Bank. Показатели в шкалах (Экономика, Народ, Армия, Политический капитал, Здоровье) являются **игровыми индексами**, а не официальными измерениями.

Источники:
- https://data.worldbank.org/country/central-african-republic
- https://data.un.org/legacy/en/iso/cf.html
- https://www.worldbank.org/ext/en/country/centralafricanrepublic

## Важные оговорки по первой версии
- Сейчас доступна только ЦАР.
- Игровой персонаж президента условный и редактируется в `DEFAULT_STATE` внутри `app.js`.
- В исходном JSON 36 событий; повторное выпадение исключено, цепные события ставятся в очередь.
- В этой демоверсии выборы проходят каждые четыре года, порог переизбрания — Народ и Политический капитал выше 40.
- Музыка пока только визуальный переключатель, аудиофайла нет.
- Авторежим/скорость — базовая механика; решения игрока всегда требуют ручного выбора.
- Некоторые цепочки и игровые параметры ещё стоит сбалансировать после тестирования.
