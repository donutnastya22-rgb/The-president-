Центральноафриканская Республика

Стартовые параметры страны основаны на опубликованных международных данных. Внутриигровые шкалы экономики, доверия, армии и политического капитала — условная игровая модель.

Важно: события в JSON — сценарный материал для симуляции, а не утверждение, что все описанные эпизоды происходили именно так. Отдельные статистические формулировки из пользовательского набора событий могут требовать дополнительной проверки.

ИНСТРУКЦИЯ

Правила игры

  • Один игровой год — один цикл решений. При высоком напряжении в год может выпадать больше событий.
  • Каждое событие можно пройти только один раз. Выбор меняет пять игровых показателей и напряжение.
  • Цепные события добавляются в очередь следующего года, если выбранный вариант их запускает.
  • Каждые четыре года проходят выборы. Для переизбрания нужны Народ и Политический капитал выше 40.
  • Политический капитал на нуле означает импичмент. После 60 лет здоровье президента постепенно снижается.
  • Сохранение работает локально в браузере этого устройства. Для переноса между устройствами понадобится отдельная база данных.
